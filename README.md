# DarkCore для Windows

<img src="https://raw.githubusercontent.com/DarkFireReal/DarkCoreRelease/main/darkcore.png" width="96" alt="DarkCore">

Доступ предоставляется только принятым участникам Discord DarkCore.

В PowerShell выполните:

```powershell
irm "https://raw.githubusercontent.com/DarkFireReal/DarkCoreRelease/main/install.ps1" | iex
```

Закройте игры и дождитесь окончания загрузок Steam перед установкой. Установщик
найдёт Steam, проверит контрольные суммы и установит DarkCore. Если Millennium
ещё не установлен, откроется его официальный установщик — завершите установку
в том же каталоге Steam. После этого установка DarkCore продолжится.
Недостающие внешние компоненты загружаются из исходной поставки; существующие
DLL не заменяются. Steam перезапустится.

Затем войдите на https://darkcore.ccwu.cc через Discord, создайте личный токен
в разделе подключения и введите его в меню DarkCore в Steam. Пароли и токен
никому не передавайте. Пока аккаунт не подключён, защищённые функции недоступны.
Заявка на вступление и незавершённая проверка Discord доступа не дают.

Для ручной установки на ПК с готовыми зависимостями распакуйте пользовательский
архив и запустите:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-DarkCore.ps1
```

При необходимости укажите `-SteamRoot "D:\Games\Steam"`. `-NoRestart` оставит
Steam закрытым. По умолчанию временная резервная копия удаляется после успешного
обновления. Для сохранения предыдущего плагина добавьте `-KeepBackup`;
`Restore-DarkCore.ps1` работает только с такой сохранённой копией.

Покупки и баланс проверяются сервером. Повторное скачивание купленной игры
не расходует новый ключ; DLC входят в основную игру. После отзыва доступа
штатный плагин удаляет принадлежащие ему неизменённые файлы при следующей
успешной синхронизации.
